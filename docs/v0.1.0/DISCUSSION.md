## 2. 待讨论议题详情

### D-001 微软登录通道 `blocked`

- **背景**：设备码 → XBL → XSTS 全通，`login_with_xbox` 返回 403
  `Invalid app registration`（Minecraft 服务端应用白名单）。
- **选项**
  - A. 申请登记（`aka.ms/AppRegInfo` 目前只跳帮助页，实际几乎无入口）
  - B. 用官方启动器 client id 走旧版授权码（可行，灰色地带，可能违反条款/随时失效）
  - C. 本版本只保留离线 + LittleSkin，微软入口标注「等待官方开放」
- **倾向**：C（不引入合规风险），B 需要负责人书面同意后才做。
- **待定**：谁去跟进 Minecraft Services 的申请渠道。

### D-002 世界分析表格化 `open`

- 现在点开存档展示 `mc2.scan` 原始 JSON。
- 建议：顶部显示种子/版本/难度，卡片列出「出生点群系」「附近结构」；数据不足时显示「未探测」。
- 待定：是否引入 region 扫描（耗时）还是只读 `level.dat` 摘要。

### D-003 原地更新器 `open`

- 现状：zip 更新解压到 `downloads/update/extracted-<ts>/`，用户手动覆盖。
- 方案：生成 `updater.bat/ps1`，主程序退出后替换 `_internal` 并重启；失败回滚备份。
- 待定：是否需要管理员权限（当前便携版不需要）。

### D-004 中文覆盖率 `open`

- 现状：ZH 词表覆盖主导航、设置、实例页标签；页面正文仍英文。
- 方案 A：抽 `t('...')` 全量包裹（改动大，回归风险）；B：只补用户高频路径（启动/下载/设置）。

### D-005 令牌加密 `open`

- 现状：`config/accounts.json` 明文存 access/refresh token。
- 方案：Windows DPAPI（`win32crypt` 或 `ctypes` 调 `CryptProtectData`），跨机器不可解密。
- 待定：是否影响后续跨平台。

### D-006 包体与安装器 `open`

- 现状：onedir 615 MB，zip 238 MB。
- 方案：① 拆分 QtWebEngine 共享运行时；② 增量更新（只传变化文件）；③ 换 NSIS 安装器。
- 待定：用户是否接受安装器（便携版更受欢迎）。

### D-007 公告站版本 `open`

- `zhanjhn.github.io/vl/public.js` 仍是 `0.0.3`，应用内横幅显示旧版本。
- 需要有人更新 Pages 仓库的 `version` / `update.version` 为 `0.1.0`。

### D-008 插件市场 `open`

- 现状：插件宿主、权限、示例插件可用，没有市场页。
- 待定：0.2.0 是否做「浏览/安装/更新」最小闭环，还是先做本地插件管理。

### D-009 镜像 SSL 降级 `open`

- 现状：BMCLAPI 部分节点证书链不完整 → 自动改用不校验会话并记住。
- 权衡：可用性 ↑，中间人风险 ↑。是否有更稳妥的 CA 补全/固定公钥方案。
