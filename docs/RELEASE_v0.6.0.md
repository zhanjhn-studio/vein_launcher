# Vein Launcher 0.6.0

发布日期：2026-11-14

## 重点更新

### 默认主题：Account
- 深色斜纹背景 + 方块纹理 + 玻璃卡片
- 主题设置新增「Account（默认）」

### 默认中文
- 界面默认简体中文
- 首次安装欢迎引导五步全部中文化：欢迎 / 功能 / 账号 / 隐私 / 完成
- 启动 Splash 中文化

### 账号与社区
- ZHANJHN 统一账号登录、设备关联、右上角账号入口、「我的」页
- 广场发帖、点赞、管理员/作者删帖
- 一键联机房间：房间号 + 可选口令，公开/私密，可同步发帖

### 远程控制
- 游戏状态、按 PID 停止、发送指令、日志自动轮询
- 版本远程安装/删除、MLC 开关、Mods 列表与启停

### 安全
- 登录/注册/设备/房间/发帖限流
- CORS 白名单、安全响应头、关闭错误堆栈
- 远程指令输入校验，阻断路径穿越

## 安装

1. 下载 `VeinLauncher-0.6.0-win64.zip`
2. 解压到任意目录
3. 运行 `VeinLauncher.exe`
4. 首次启动显示中文欢迎引导

## 系统要求

- Windows 10 / 11 64 位
- Java 由启动器自动探测/下载
- 账号：离线 / 微软 / LittleSkin / ZHANJHN
