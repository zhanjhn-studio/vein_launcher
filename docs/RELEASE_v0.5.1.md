# Vein Launcher 0.5.1

发布日期：2026-11-14

## 本次更新

### 主题
- 新增 **Account 深色纹理主题**，作为默认主题：深色斜纹背景 + 方块纹理 + 深色玻璃质感卡片
- 主题选择新增「Account（默认）」，可随时切回 Dark / Light / Clear

### 中文默认
- 默认语言改为中文（简中）
- 首次安装欢迎界面全部中文化：欢迎、功能、账号、隐私、完成五步
- 启动 Splash 提示中文化

### 账号
- ZHANJHN 统一账号登录 / 设备关联
- 账号头像与昵称显示在右上角，「我的」页统一管理
- 发帖身份取账号，不再需要填写昵称

### 联机
- 一键开房：房间号 + 可选口令，公开 / 私密
- 房间可同步发布到广场
- 公开房间列表、加入房间、地址复制

### 远程控制
- 游戏状态、停止（可按 PID）、发送指令、读取日志
- 版本安装 / 删除、MLC 开关、Mods 列表与启停
- 日志自动轮询（15 秒）

### 安全
- 登录 / 注册 / 设备 / 房间 / 发帖限流
- CORS 白名单、安全响应头、关闭错误堆栈
- 远程指令输入校验，阻断路径穿越

## 安装

1. 下载 `VeinLauncher-0.5.1-win64.zip`
2. 解压到任意目录
3. 运行 `VeinLauncher.exe`
4. 首次启动会显示中文欢迎引导

## 系统要求

- Windows 10 / 11 64 位
- 需要安装 Java（启动器可自动探测并下载匹配版本）
- 账号：离线 / 微软 / LittleSkin / ZHANJHN 统一账号
