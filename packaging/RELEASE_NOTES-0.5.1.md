# Vein Launcher 0.5.1

一次以「界面」为主的更新：默认浅色、橙色主题、更多自定义，以及全部图片重制。

## 新增

- **默认浅色主题**：首次启动即为浅色；设置里可切深色 / 透明 / 跟随系统
- **橙色主题**：主色改为橙色（`#f97316` / `#f59e0b`），仍可自由更换任意主色
- **界面自定义**：
  - 圆角：小 / 中 / 大
  - 界面缩放：95% / 100% / 105%
  - 动效开关：关闭后全站动画与过渡停用
- 启动器截图与图标全部重制（官网同步换新）

## 变更

- 默认主题从深色改为浅色（**破坏性改动**，可在设置切回深色）
- 调色板预设改为橙色优先

## 修复

- 清理旧版残留配色（紫色光晕、旧蓝）

## 安装

- Windows 10/11 x64，解压 `VeinLauncher.exe` 即用
- 数据目录仍在 exe 同级 `VeinLauncher/`，覆盖升级不影响实例与配置

- 51 项单元测试通过
